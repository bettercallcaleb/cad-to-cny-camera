# Security and privacy

Please avoid posting sensitive photos, receipts, payment details, addresses, or signing material in public issues.

If you believe you found a security or privacy issue, contact the maintainer through the GitHub profile before publishing exploit details. For ordinary OCR accuracy bugs, open a normal issue with the smallest non-sensitive reproduction you can provide.

Never commit Android signing keystores or credentials. The repository is configured to ignore common keystore formats and local signing property files.
